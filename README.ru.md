# screen-off

*[English version](README.md)*

Ночной режим экрана для ноутбука под Windows — и скилл для [Claude Code](https://claude.com/claude-code),
чтобы включать его командой `/screen-off` из любого диалога, хоть с телефона.

Зачем: ноутбук работает ночью (удалённый доступ, долгие сборки, что угодно), а светящаяся
панель мешает спать. Штатного способа погасить только экран у многих ноутбуков нет —
аппаратная кнопка вроде `Fn+F(что-то)` есть далеко не везде.

## Что делает

Затемняет экран, **не усыпляя компьютер**: он продолжает работать и остаётся доступен по сети.

По умолчанию (`/soft`):

- яркость панели выставляется в 0 (исходная запоминается и возвращается при выходе);
- поверх всего показывается чёрное полноэкранное окно, курсор прячется;
- системе запрещено засыпать и гасить дисплей самой (`ES_SYSTEM_REQUIRED | ES_DISPLAY_REQUIRED`).

Питание панели при этом не выключается — и это принципиально, см. «Почему не power-off».

## Проверено на

ThinkPad 21A0 (T14 Gen 2), Windows 10 Pro 19045, .NET Framework 4.8. Должно работать на
любом ноутбуке под Windows, где яркость управляется через WMI; если не управляется — режим
просто не трогает яркость, а чёрное окно всё равно закрывает экран.

## Установка

Нужен Windows с .NET Framework 4.x (есть в системе по умолчанию). Компилятор `csc.exe`
берётся оттуда же, ставить ничего не надо.

```powershell
git clone https://github.com/iktarru/screen-off.git
cd screen-off
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

`install.ps1` собирает `DisplayOff.exe` в `%USERPROFILE%\Tools`, кладёт скилл в
`%USERPROFILE%\.claude\skills\screen-off\` и создаёт на рабочем столе ярлык
`Display Off` с горячей клавишей `Ctrl+Alt+D`.
Права администратора не нужны.

**Собранного бинарника в репозитории нет намеренно.** Неподписанный exe от незнакомого
человека — вопрос доверия; сборка из исходников занимает две секунды, и перед запуском
можно прочитать, что именно вы запускаете.

## Как пользоваться

| Действие | Как |
|---|---|
| Погасить экран | `Ctrl+Alt+D`, ярлык на рабочем столе, или `/screen-off` в Claude Code |
| Вернуть экран | то же самое — это переключатель |
| Аварийный выход | `Esc` три раза подряд за 2 секунды |
| Само выключится | через 10 часов (`/timeout:СЕКУНДЫ` меняет) |

Скилл в Claude Code понимает и обычные просьбы: «погаси экран», «включи экран».
Удобно, когда сидишь с телефона, а ноутбук в другой комнате.

### Аргументы

```
DisplayOff.exe [задержка_мс] [/timeout:СЕКУНДЫ] [/soft|/hard]
```

- **задержка_мс** — пауза перед затемнением, по умолчанию 700. Нужна при запуске с
  клавиатуры: без неё отпускание `Ctrl+Alt+D` тут же будит экран. Из терминала передавайте `0`.
- **/timeout:СЕКУНДЫ** — предохранитель, по умолчанию 10 часов.
- **/hard** — старое поведение: питание панели выключается и переустанавливается каждые
  120 мс. Темнее, но см. ниже.

## Почему не power-off

Очевидный способ погасить экран — послать `WM_SYSCOMMAND / SC_MONITORPOWER`. На машинах
с **Modern Standby (S0 Low Power Idle)** это плохо кончается:

- Windows считает выключенную панель поводом уйти в «подключённый сон»;
- при `CONSOLELOCK = 1` в схеме питания сеанс блокируется, и при возврате нужен пароль;
- а любое касание тачпада будит панель обратно — со вспышкой света, ровно того, от
  которого мы уходили.

Заблокировать это касание изнутри Windows нельзя: панель просыпается в драйверном стеке
ввода раньше, чем событие дойдёт до любой программы. Проверено буквально — глобальные
хуки, глушащие мышь и клавиатуру целиком, вспышки не убирают. Поэтому режим `/soft`
панель не выключает вовсе: гасить нечего, будить нечего, вспышек нет.

Проверить свою машину:

```powershell
powercfg /a                                             # есть ли S0 Low Power Idle
powercfg -attributes SUB_NONE CONSOLELOCK -ATTRIB_HIDE  # показать настройку (нужен админ)
powercfg /q SCHEME_CURRENT SUB_NONE                     # CONSOLELOCK: 1 = просит пароль
```

Отключить запрос пароля (нужны права администратора):

```powershell
powercfg /SETACVALUEINDEX SCHEME_CURRENT SUB_NONE CONSOLELOCK 0
powercfg /SETDCVALUEINDEX SCHEME_CURRENT SUB_NONE CONSOLELOCK 0
powercfg /S SCHEME_CURRENT
```

## Ограничения

- **Подсветка клавиатуры не выключается.** На ThinkPad ею управляет встроенный
  контроллер: ни Lenovo WMI, ни HID Lighting, ни BIOS-интерфейс до неё не дают доступа,
  а `Fn` до Windows не доходит и эмуляции не поддаётся. Гасите вручную — `Fn+Space`.
- Яркость меняется через WMI (`WmiMonitorBrightnessMethods`). Если ноутбук её не
  поддерживает, режим просто не трогает яркость — чёрное окно остаётся.
- WMI умеет применить яркость и «зависнуть» на минуту, не возвращая управление, поэтому
  каждый такой вызов живёт в отдельном потоке с таймаутом, а восстановление яркости
  проверяется чтением и повторяется до трёх раз.

## Аварийная остановка

Если процесс завис:

```powershell
Stop-Process -Name DisplayOff -Force
(Get-WmiObject -Namespace root/wmi -Class WmiMonitorBrightnessMethods).WmiSetBrightness(0,100)
```

Вторая строка обязательна: после принудительной остановки яркость останется 0.

Лог включений и выключений с причиной выхода — `%USERPROFILE%\Tools\displayoff.log`.

## Удаление

```powershell
Remove-Item "$env:USERPROFILE\Tools\DisplayOff.exe", "$env:USERPROFILE\Tools\DisplayOff.cs", "$env:USERPROFILE\Tools\displayoff.log" -ErrorAction SilentlyContinue
Remove-Item "$env:USERPROFILE\.claude\skills\screen-off" -Recurse -ErrorAction SilentlyContinue
Remove-Item (Join-Path ([Environment]::GetFolderPath('Desktop')) 'Display Off.lnk') -ErrorAction SilentlyContinue
```
